# TOEIC 준비

TOEIC 시험 대비용 단어/숙어/문법 정리 및 이해도 진행 상황 확인 페이지.

## 실행 방법

`D:\Claude Data\.claude\serve.ps1` 을 실행해 로컬 서버를 띄운 뒤, 브라우저에서
`http://127.0.0.1:8080/Dashboard0/toeic-prep/index.html` 로 접속하세요.

또는 `index.html` 파일을 브라우저로 직접 열어도 됩니다.

## 기능

- **단어 및 숙어** / **문법** 두 카테고리로 항목 등록
- 항목 추가 시 자동으로 뜻을 검색해 저장 (찾지 못하면 직접 메모에 입력)
  - 한국어 뜻: [MyMemory Translation API](https://mymemory.translated.net/)
  - 영어 정의/예문: [Free Dictionary API](https://dictionaryapi.dev/)
- 항목별 이해도 상태(미숙지/학습중/이해함) 표시 및 메모 작성
- **진행 상황** 탭에서 카테고리별 등록 개수와 이해도 비율 확인
- 데이터는 브라우저(localStorage)에 저장되며, CSV 내보내기/불러오기로 백업 및 이동 가능

## 알려진 제한 사항

- MyMemory는 기계 번역 기반이라 뜻이 부정확하거나 문맥에 안 맞을 수 있습니다. 특히 숙어(여러 단어로 된 표현)는 직역되어 나올 수 있어 직접 확인이 필요합니다.
- MyMemory 무료 사용량은 익명 기준 일일 약 5,000단어로 제한되어 있어, 사용량이 많으면 한국어 뜻이 비어 있을 수 있습니다.
- Free Dictionary API도 영어 사전 기반이라 숙어나 전문 문법 용어는 검색이 안 될 수 있습니다.
- 데이터는 브라우저별로 저장되므로 다른 기기/브라우저에서는 CSV로 내보낸 뒤 불러와야 합니다.
